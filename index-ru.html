Как это работает

Получить API ключ → Отправить токены → Получить результат проверки

1

Получить API ключ

Зарегистрируйтесь, создайте проект и включите проверки LVL / Play Integrity.

2

Отправить клиентские токены

Передайте LVL-ответ и токен Play Integrity (DG). Поддерживается защита от подделки и повторных запросов.

3

Получить оценку риска

Сервер возвращает результат проверки, оценку целостности и уровень риска для принятия решений.
